## 选机场前要知道的事

1. **没有永久稳的** —— 线路会被干扰，"任何机场"都有可能跑路，**是任何机场**，别一次买太长时间。 
2. **线路比流量重要** —— 1000G 慢速线路不如 100G 优质线路。
3. **至少两个机场** —— 主力 + 备用，一个挂了不至于失联。
4. **先试用再付款** —— 能试用先试用，不能试用的就先买一个月试水。
5. **太便宜的留个心眼** —— 低于市场定价的，除非是新机场赔本引流，不然要么超售要么准备跑路。
6. **机场客户端推荐:**
>Windows：Clash-verge-rev、FlClash、V2rayN、Clash-Party 
Mac：Clash-verge-rev、FlClash、Clash-Party

安卓：FlClash、Flyclash、ClashMetaforAndroid  
linux：Shell clash（命令行）、Mihomo-Party、clash-verge-rev、FLClash

## 常见问题

**为什么别人用的很好，我的却不行？** 

这个跟地区，运营商，甚至代理工具都有关系，比如新疆，福建，翻墙难度对比其他地区的墙就更高。

**延迟低为什么速度不快？** 

在带宽和占用正常的情况下，延迟跟速度没有关系，比如中国到美国的物理极限是120ms，难道就一定比香港慢吗？

**为什么测速快实际体验不好？**

测速可能是白天测速的，晚高峰使用的人多带宽不足。

也可能你的问题，排查顺序：不挂梯测速，地区，挂梯子测速，群里询问

**买月付还是年付？** 

第一次建议月付/季付，用习惯再考虑年付。

**建议买几个？** 

至少两个。一个主力日常用，一个备用以防万一。

**为什么官网打不开？** 机场域名经常会被污染，一般都有备用域名。建议加个 TG 频道方便收到最新地址。
